# Demonstrations and provenance

| Presentation | File | Scope |
|---|---|---|
| Social demo | [Portrait video](media/hyperkut-demo-official.mp4) | Author-selected presentation, 111.3 seconds, 540×960, with audio; supplied file preserved unchanged. |
| README demo | [Landscape walkthrough](media/hyperkut-demo-readme.mp4) | About 107 seconds, 1280×720 delivery, English narration. Simulated cursor, typing, progress, correction and trim, built from actual Studio component markup. |

The README demo includes a real saved fashion result; simulated actions are not proof of a newly computed regeneration or inference-speed measurements. Separate screenshots in the README were captured from the actual local interface.

README-demo production: HyperFrames/GSAP for animation, FFmpeg for assembly, locally synthesized presentation accents/music and authorized ElevenLabs voice narration through Magnific. These presentation services are distinct from the Studio's maintained local model workflow. [Presentation file hashes](media/presentation-demos.json).

The "Under the hood" section before the outro (VideoTools nodes, the three workflows, automation and the server flow) is an animated HyperFrames explainer, not a screen recording. Its narration uses the same voice, cloned with ComfyUI's ElevenLabs Instant Voice Clone node from the demo's own voice excerpt.

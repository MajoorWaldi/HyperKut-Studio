## Repeat the workflow

1. Follow [installation](../installation.md). Provision the matching models and inspect their license conditions.
2. Open the Studio, select Remix and upload a video you are permitted to use. Add your own character reference to the first visual slot.
3. Enter the brief and choose Standard, 9:16, original audio and seed 20261025. Keep finishing disabled for this baseline. Use the saved JSON to inspect the historical request; it is not a preset-import file or executable API payload.
4. Generate once. Review the actual plan, identities, motion and soundtrack; a seed alone does not make LLM planning or model output deterministic.
5. Select a shot, review its prompt and current take, then choose another source window if needed. Explicitly apply/export only when you intend to change your project.
6. If testing regeneration, correct a single shot and regenerate it. Check retained takes and verify that other active takes are preserved. This costs another generation; no such rerun was performed for this document.

## Reproduction boundary

The original source video is **not distributed**, following the existing media-rights review. The portrait's owner authorized redistribution previously, but that permission does not clear the source video or retained soundtrack. The recipe publishes hashes and roles, not private asset copies.

With different authorized media, this reproduces the workflow, not the same frames. An exact, publicly reproducible example still needs a cleared source video, packaged inputs, pinned model revisions and a clean-install GPU rerun. Do not mark that release item complete yet.
